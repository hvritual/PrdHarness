# PrdHarness

Canonical Semantic Document based PRD Harness, built in Go.

## Roadmap

The authoritative implementation plan is tracked in [Issue #1](https://github.com/hvritual/PrdHarness/issues/1). It contains 19 implementation issues across MVP, Full Runtime, and Production.

Current task: [CSD-01 Semantic Document Core](https://github.com/hvritual/PrdHarness/issues/2).

This initial commit establishes the repository only. Implementation and verification will be delivered in a separate, reviewable pull request. No LLM, product gate, approval system or UI is implemented in this baseline.

## Principles

One semantic authority, read-only projections, stable identities, explicit unknowns, version-bound evidence, and AI proposals that cannot approve themselves.

A semantic hash is a digest of explicitly specified fields, not proof of natural-language equivalence or trusted authorship.
